# Contributing to Coda

Thanks for your interest in contributing. Coda is a solo side project built with AI assistance, so the bar for external contributions is intentionally kept simple.

## Reporting bugs

Use the [Bug Report](https://github.com/graphicsprocessingunit/Coda/issues/new?template=bug_report.md) template. Include your device, OS version, and app version (Settings → About).

## Feature requests

Use the [Feature Request](https://github.com/graphicsprocessingunit/Coda/issues/new?template=feature_request.md) template. Describe the problem you're trying to solve, not just the solution.

## General questions / contact

Use the [Contact / Other](https://github.com/graphicsprocessingunit/Coda/issues/new?template=contact.md) template.

## Pull requests

External PRs are accepted on a case-by-case basis. Before opening one:

1. Open an issue first describing what you want to change and why — don't submit code without prior discussion.
2. Keep changes focused: one issue, one PR.
3. Match the existing code style (TypeScript strict, no comments unless asked for, functional where possible).
4. Run `npx tsc --noEmit` and `npm test` before submitting.
5. Describe what changed and why in the PR description.
