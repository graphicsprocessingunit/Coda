About

What is Coda?

Coda is a music player for iOS and Android built with Expo and React Native. Import your local library, connect to a Navidrome server, or both. Enjoy crossfade, gapless playback, synced lyrics, and four beautiful themes — all without ads or subscriptions.

Get Started

Install Coda

Android

APK Download

  1. Download the APK from the button above
  2. Open the file on your Android device
  3. Enable Install from unknown sources if prompted
  4. Tap Install

iOS

IPA Sideload

  1. Download the IPA from the button above
  2. Sideload using AltStore, SideStore, or any IPA signing tool
  3. Trust the developer profile in Settings → General → VPN & Device Management
Apps signed with a free Apple ID expire after 7 days and must be refreshed.

For Developers

Build from source

# Clone the repository
$ git clone https://github.com/graphicsprocessingunit/Coda.git
$ cd Coda

# Install dependencies
$ npm install

# Generate native projects and start dev server
$ npx expo prebuild --clean
$ npx expo start
