# Security Policy

If you discover a security vulnerability in Coda, please report it responsibly.

## Reporting a vulnerability

1. Open a [security advisory](https://github.com/graphicsprocessingunit/Coda/security/advisories/new) on GitHub, or email the maintainer directly if you prefer.
2. Include a clear description of the issue, steps to reproduce, and the potential impact.
3. Do not disclose the vulnerability publicly until a fix has been released.

## What to expect

- Acknowledgment within a reasonable time (this is a solo project — expect days, not hours).
- A fix released as soon as practical once the issue is confirmed.
- Credit in the release notes if desired (anonymous reporting is also fine).

## Scope

Coda is a client-side app — it connects to user-controlled Navidrome servers and Last.fm. Security issues in third-party services (Navidrome, Last.fm, LRCLIB) are out of scope; report those upstream.
